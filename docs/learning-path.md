# Learning path

1. **Dashboard** — see mode (demo), cash, open positions summary.
2. **Markets** — browse binary YES/NO markets from fixtures.
3. **Order Book** — inspect levels; compute spread and midpoint.
4. **Research** — run observations (spread, imbalance, pair cost). Treat as
   hypotheses, not guaranteed opportunities.
5. **Paper Portfolio** — place paper buys of YES or NO; watch fills and PnL.
6. **Journal** — review decisions and outcomes for reflection.
7. **Help** — recall limits and safety rules.

Suggested exercise: pick one market, estimate a fair probability, compare to
midpoint, size a small paper order within educational limits, then journal why.
